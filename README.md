# Selected engineering projects

Below are selected projects related to embedded systems, robotics, PCB design and mechatronics.

## Portfolio projects

These projects are described in more detail in my portfolio PDF.

| Project | Description | Technologies |
|---|---|---|
| [6DOF Manipulator](https://github.com/Wudker/6DOF_Manipulator) | Educational robotic manipulator developed as an engineering thesis project, including kinematics, embedded control and custom electronics. | ESP32, C++, robotics, PCB |
| [Weather Station](https://github.com/Wudker/Weather_station) | Solar-powered ESP32 weather station with ESP-NOW communication and local web dashboard. | ESP32, ESP-NOW, sensors, low-power |
| [S.M.U. RLC Meter](https://github.com/Wudker/S.M.U) | Raspberry Pi Pico based RLC meter using ADC measurements, RC timing and LC resonance. | Raspberry Pi Pico, analog circuits, C/C++ |
| [Suntracker](https://github.com/Wudker/Suntracker) | Solar tracker powerbank with MPPT control, motorized panel positioning and custom PCB design. | STM32, MPPT, PCB, low-power, motor control |
| [Clickfy](https://github.com/Wudker/Clickfy) | Compact ESP32-C3 BLE multimedia remote with custom PCB, battery monitoring and low-power operation. | ESP32-C3, BLE HID, C/C++, PCB |
